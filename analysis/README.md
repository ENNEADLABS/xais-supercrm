# Analyses historiques

Ce dossier conserve les analyses de CRM open source qui ont nourri le prototype.
Les dépôts de référence étudiés ne sont pas inclus et les chemins mentionnés dans
certaines notes sont historiques.

Ces textes expliquent les inspirations et anti-patterns observés ; ils ne constituent
ni une documentation utilisateur ni une description garantie du code actuel. Pour la
source canonique, commence par le [`README`](../README.md),
[`docs/layout.md`](../docs/layout.md) et les [`ADR`](../docs/decisions/).
